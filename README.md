# Multi-radius-closet-packing
The classical closet packing problem in dimension $n$ uses balls with radius $1$. In this problem, we allow balls with radius $1,2, ... ,k$. This is an open problem which is still not fully discovered, and we believe researching it will bring new understandings in packing strategies.

The most basic case which remains unresolved is when $n=2$ and $k=3$.
